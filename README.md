# Ovlira

A responsive freelance marketplace website built with HTML, CSS, and JavaScript. Ovlira provides a modern interface for exploring freelance work, discovering service categories, and browsing freelancer portfolios.

## 🌐 Live Demo

[View Ovlira Website](https://muhaned-7.github.io/Ovlira/)

## ✨ Features

- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Navigation Bar:** Includes a responsive mobile menu.
- **Hero Section:** Features an introduction, call-to-action buttons, and a search interface.
- **How It Works:** Explains the basic steps for getting started.
- **Freelancer Statistics:** Highlights freelancers and posted work opportunities.
- **Recently Posted Works:** Displays freelance projects with descriptions and bid information.
- **Categories:** Showcases different freelance service categories.
- **Freelancer Portfolios:** Displays sample freelancer profiles and specializations.
- **Newsletter Subscription:** Includes an email subscription form.
- **Modern UI:** Clean layout, consistent colors, and interactive hover effects.

## 🛠️ Technologies Used

- **HTML5:** Structures the website content.
- **CSS3:** Handles styling, layouts, transitions, and responsive design.
- **JavaScript:** Adds interactive behavior and DOM manipulation.
- **Font Awesome:** Provides icons throughout the website.
- **Google Fonts (Poppins):** Provides the website typography.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- The Live Server extension for Visual Studio Code (optional).

### Installation

1. Clone the repository:

```bash
   git clone https://github.com/Muhaned-7/Ovlira.git
```

2. Navigate to the project directory:

```bash
   cd Ovlira
```

3. Open the project folder in Visual Studio Code.
4. Open `index.html` in your browser, or use the Live Server extension.
